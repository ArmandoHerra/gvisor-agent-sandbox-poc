# gVisor Claude Sandbox PoC

Proof of concept for sandboxing Claude Code tool execution using gVisor (runsc). This project explores using gVisor's application kernel to provide a secure, isolated execution environment for AI agent tool calls — particularly Bash commands — without the overhead of full virtual machines.

## Getting Started

### Prerequisites

- Linux host (gVisor only runs on Linux)
- [gVisor (runsc)](https://gvisor.dev/docs/user_guide/install/) installed
- Docker (optional, for container-based sandboxing)

### Setup

